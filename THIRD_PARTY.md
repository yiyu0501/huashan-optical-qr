# Third-party libraries

The hosted pages load these libraries from public CDNs. The service worker runtime-caches them after the first successful load.

- **qrcode.js 1.0.0** — https://github.com/davidshimjs/qrcodejs — MIT License
- **jsQR 1.4.0** — https://github.com/cozmo/jsQR — Apache License 2.0

No Decimen source code is copied into this repository. The screen-to-camera transfer concept and event workflow were inspired by Decimen Optical Transfer.
